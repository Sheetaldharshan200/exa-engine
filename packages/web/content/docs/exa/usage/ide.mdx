Exa integrates with VS Code, Cursor, or any IDE that supports a terminal. Just run `exa` in the terminal to get started.

<Callout type="info" title="Prefer a full graphical client?">
[Exasol Studio](https://github.com/Sheetaldharshan200/Exasol-studio) is the desktop app built on this same engine — schema browser, SQL editor, dashboards, and the agent in one window. `exa web` serves the same app in your browser; see [Web](./web.mdx).
</Callout>

---

## Usage

- **Quick Launch**: Use `Cmd+Esc` (Mac) or `Ctrl+Esc` (Windows/Linux) to open Exa in a split terminal view, or focus an existing terminal session if one is already running.
- **New Session**: Use `Cmd+Shift+Esc` (Mac) or `Ctrl+Shift+Esc` (Windows/Linux) to start a new Exa terminal session, even if one is already open. You can also click the Exa button in the UI.
- **Context Awareness**: Automatically share your current selection or tab with Exa.
- **File Reference Shortcuts**: Use `Cmd+Option+K` (Mac) or `Alt+Ctrl+K` (Linux/Windows) to insert file references. For example, `@File#L37-42`.

## Installation

To install Exa on VS Code and popular forks like Cursor, Windsurf, VSCodium:

1. Open VS Code
2. Open the integrated terminal
3. Run `exa` - the extension installs automatically

If on the other hand you want to use your own IDE when you run `/editor` or `/export` from the TUI, you'll need to set `export EDITOR="code --wait"`. [Learn more](./tui.mdx#editor-setup).

### Manual Install

The extension ships with the CLI, so the automatic install above is the supported path. A marketplace listing is coming; until then, re-running `exa` inside the IDE's terminal reinstalls or updates it.

### Troubleshooting

If the extension fails to install automatically:

- Ensure you’re running `exa` in the integrated terminal.
- Confirm the CLI for your IDE is installed:
  - For VS Code: `code` command
  - For Cursor: `cursor` command
  - For Windsurf: `windsurf` command
  - For VSCodium: `codium` command
  - If not, run `Cmd+Shift+P` (Mac) or `Ctrl+Shift+P` (Windows/Linux) and search for "Shell Command: Install 'code' command in PATH" (or the equivalent for your IDE)
- Ensure VS Code has permission to install extensions
