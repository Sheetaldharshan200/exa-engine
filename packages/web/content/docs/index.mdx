One engine underneath, two front doors on top. These docs are split the same way — switch between them any time with the tabs.

## [Exa](./exa/index.mdx)

The AI agent for your data: the terminal TUI, the engine, providers and local models, databases with opt-in writes, plugins and the SDK — and `exa web`, which serves Exasol Studio in your browser.

## [Exasol Studio](./studio/index.mdx)

The desktop and web application: schema browser, SQL editor with query performance, dashboards, the marketplace of managed components, security, and the built-in AI assistant.
