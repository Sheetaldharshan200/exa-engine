## The Settings window

A separate window, searchable and auto-saving, with two tabs and per-category *Restore defaults*:

**General** — Appearance (system/light/dark theme, interface font size, density, color-theme presets) · Database Objects Tree (system schemas, auto-expand) · Metadata cache (persistent/transient/disabled, staleness threshold) · **SQL Editor** (font size, word wrap, statement-number badges, auto-completion, delimiter, and a full **syntax-color editor** — eight token kinds, dark and light separately, live preview) · Result Grid (max rows, NULL display, font size, zebra striping) · Execution (statement splitting, stop-on-error, auto-commit, comment stripping) · SQL History (keep, limit) · Telemetry (anonymous, **off by default**).

**Database (Exasol)** — default schema, identifier quoting, connect/query timeouts, compression, TLS policy, transaction defaults, charset, fetch size, query-builder LIMIT.

## Theme customizer

The palette button in the title bar: eleven presets (Exasol default, Modern Minimal, Catppuccin, Doom 64, …), a custom accent color, interface and code font choices, corner radius — and reset.

## Keyboard shortcuts

| Shortcut | Action |
| --- | --- |
| `⌘⏎` | Execute the buffer as a script |
| `⌘.` | Execute the current statement |
| `⌘⇧⏎` | Execute the buffer as one statement |
| `⌘⌥⏎` | Explain plan |
| `⌘⇧E` | AI: explain the plan |
| `⌘P` / `⌘⇧P` | Quick Access / command palette |
| `⌘F` | Search tables in the visualizer |
| `F3` / `⇧F3` | Next / previous object-search match |
| `⌘⏎` | Run the current notebook cell |
| `Enter` / `⇧Enter` | Send in the assistant / newline |
| Middle-click a tab | Close it |

## Notifications & updates

A persistent notifications center (kept until deleted, click-to-navigate, mark-all-read) and an auto-update banner — download with progress, install, restart — that minimizes to a corner pill.
