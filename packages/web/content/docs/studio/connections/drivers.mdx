---
title: Drivers
description: Managed driver runtimes, installed per machine.
---

The **Drivers** tab lists every driver Studio knows: installed / not-yet-supported badges, a per-driver install button with context, and documentation links.

Studio's own connections use the **bundled WebSocket driver** — nothing to install. The managed installs exist for the tools around it: JDBC and ODBC runtimes, PyExasol and SQLAlchemy in a managed Python environment. A JDBC driver can also point at your own `.jar`, with a one-click return to the managed one.

Reference drivers that live in your own project (TypeScript/JS, Go, ADO.NET, R, the raw WebSocket API) link out from the [Marketplace](../marketplace.mdx) instead — each card carries its GitHub docs.
