---
title: Dashboards
description: Pin query results into live dashboards.
---

Any query result can become a dashboard panel: pin it, choose a visualization, and the dashboard re-runs the query against the live connection when opened.

- **System dashboards** ship with Studio (sessions, storage, performance) — their panels are locked; you cannot delete parts of a built-in view.
- **Your dashboards** are fully editable: add panels from the SQL editor's *Show in Dashboard* action, rearrange, rename, remove.
- Dashboards open as workbench tabs, next to your SQL — not in a separate mode.

Every panel carries its SQL with it. There is no separate BI layer to configure: the query you inspected is the query the panel runs.
