Notebooks mix analysis and narrative. Keep several, named, switchable; rename and delete from the header.

## Three cell types

- **SQL** — Monaco with the same Exasol completion as the editor; `⌘⏎` runs the cell into a result table or an automatic chart; *Ask Exa about this SQL* hands it to the assistant.
- **Markdown** — a WYSIWYG editor: headings, bold/italic/underline/strikethrough, inline code, lists, quotes, code blocks, links, images from disk, text color and size, and full table editing, with a preview/code toggle.
- **Mermaid** — rendered diagrams with an edit-code toggle and *Ask Exa about this diagram*.

Cells add from the toolbar or between-cell insert zones, move by drag or arrows, and **Run all** executes top to bottom. A data-sources bar shows chips for each connected database.

## In and out

**Import** pulls dashboard panels in as cells; **Export** writes the whole notebook as Markdown, HTML, or PDF.
