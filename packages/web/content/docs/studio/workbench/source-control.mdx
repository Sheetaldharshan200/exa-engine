---
title: Source control
description: Git for your SQL workspace, built in.
---

The Source Control panel manages the `~/ExasolStudio` workspace as a git repository — **Init repo** when there is none, honest guidance when git itself is missing.

- **Branches**: switch across local and remote, create new ones; Fetch, Pull, Push.
- **Changes**: staged and unstaged sections with stage/unstage all or per file, discard (confirmed), and click-to-diff on any file.
- **Commit** with a message box, and set the remote URL when none is configured — your SQL, versioned and pushed like any other code.
- A commit-graph view shows where you are.
