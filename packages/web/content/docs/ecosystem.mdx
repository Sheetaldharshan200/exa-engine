Nothing is published here yet — Exa's plugin and integration catalog starts empty, on purpose. Everything listed on this page will be something that actually works with Exa, tested against it, not inherited from somewhere else.

What exists today is the machinery to build on:

- **[Plugins](./plugins.mdx)** — hook into events, add authentication methods, wrap tool execution. A plugin is one JavaScript file or an npm package.
- **[Custom tools](./custom-tools.mdx)** — give the agent new abilities with a typed `tool()` definition.
- **[SDK](./sdk.mdx)** — drive Exa programmatically from your own application.
- **[Server](./server.mdx)** — the HTTP API every client (TUI, Studio, SDK) already speaks.
- **[Exasol Studio](https://github.com/Sheetaldharshan200/Exasol-studio)** — the desktop and web application built on this same engine, and the largest integration there is.
