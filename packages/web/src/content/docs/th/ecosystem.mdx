ชุดโครงการชุมชนที่สร้างขึ้นบน Exa

:::note
ต้องการเพิ่มโครงการที่เกี่ยวข้องกับ Exa ของคุณลงในรายการนี้หรือไม่ ส่งพีอาร์.
:::

คุณยังสามารถลองดู [awesome-exa](https://github.com/awesome-exa/awesome-exa) และ [exa.cafe](https://exa.cafe) ซึ่งเป็นชุมชนที่รวบรวมระบบนิเวศและชุมชนไว้ด้วยกัน
