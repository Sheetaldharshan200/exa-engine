Eine Sammlung von Community-Projekten, die auf Exa basieren.

:::note
Möchten Sie Ihr Exa-bezogenes Projekt zu dieser Liste hinzufügen? Senden Sie einen PR.
:::

Sie können sich auch [awesome-exa](https://github.com/awesome-exa/awesome-exa) und [exa.cafe](https://exa.cafe) ansehen, eine Community, die das Ökosystem und die Community zusammenfasst.
