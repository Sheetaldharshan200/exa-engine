Una colección de proyectos comunitarios construidos en Exa.

:::note
¿Quieres agregar tu proyecto relacionado con Exa a esta lista? Envíe un PR.

También puedes consultar [awesome-exa](https://github.com/awesome-exa/awesome-exa) y [exa.cafe](https://exa.cafe), una comunidad que agrega el ecosistema y la comunidad.
